Product · 2020

Marginalia — an annotation tool for slow readers.

A browser extension that let you mark up the web with a small set of expressive marks — a curl for "interesting", a question for "what does this mean?", a line for "remember this". Quietly used by a small, devoted audience.

Type
Browser extension
Role
Designer + co-founder
Lifespan
2020 — 2022
Status
Sunset

Marginalia was an experiment in giving the web a kind of pencil. A small browser extension that let you mark up any page with five expressive marks, and only those five marks.

The constraint was the point. We resisted every well-meaning request for "could you add highlighting?" and "what about colors?" and "why not text annotations?". The five marks were what made it itself.

It found a small, devoted audience of academic readers, lawyers, and a handful of poets. We sunset it in 2022 when the team disbanded. The data export is still available on request.
